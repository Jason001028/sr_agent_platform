# 云查看与标注 Web 端（第一版）

## 启动

双击应用目录中的 `run_cloud_review_web.bat`。程序会启动本机服务并打开：

```text
http://127.0.0.1:8765/
```

服务只监听本机地址，不需要互联网，也不会把影像发送到其他机器。关闭 BAT 窗口即可停止服务。

网页刚打开时只显示空的空间画布，不读取数据库、不搜索盘阵，也不生成任何影像缓存。需要查看数据时，手动点击左上角的 `↻` 加载待复核队列，或者展开“组合检索”后点击相应的加载按钮。

## 空间复核

- 左侧是待复核景列表，可按影像 ID、卫星或计划号过滤。三种云量支持六种优先顺序，后台计算全部完成后统一排序一次。
- “组合检索”要求同时填写日期和计划号，也支持输入一批指定影像 ID；若路径本身就是内层 `_L1_MSS` 景目录，可直接加载该目录。
- 默认勾选“加载前先验证数量”。验证阶段只检查固定目录和文件是否存在，不打开 JPG 或 TIF；确认后先显示列表和空间范围，三种云量随后在后台补齐。
- 右侧空间画布按 `*_meta.xml` 中的四角经纬度放置影像；XML 不可用时沿用原程序的 shp 范围。
- 空间画布使用 Web Mercator（EPSG:3857）显示公式，影像、掩膜、边界、矢量底图、缩放和平移共用同一投影；高纬度地区不会再因直接把经纬度当作等距坐标而被横向过度拉伸。Web Mercator 纬度范围限制为约 ±85.0511°。
- 快视图和云掩膜不再只把四角连接成两块大三角形，而是使用 Web Mercator 网格重投影：总览采用 8×8 网格，选中景采用 16×16 网格。影像内部、掩膜和加密边界使用同一组投影点，降低高纬度和倾斜四边形中的局部拉伸及对角线折痕。
- WebGL纹理不再额外执行一次 Y 方向翻转；图片第 0 行绑定到 meta.xml 的左上—右上边，与 CPU 网格回退路径和 ArcMap 的地理行方向保持一致。快视图及综合、RDC、Omni、最终结果四种掩膜共用这一方向规则，避免影像与掩膜上下颠倒或彼此错位。
- 地图世界范围固定为 Web Mercator 正方形：投影 X/Y 均为 `-180～180`，对应经度 `-180°～180°`、实际纬度约 `-85.0511°～85.0511°`。地图只做等比例放大缩小，不能横向或纵向单独拉伸；缩小时不会小于全球范围，拖动时也不能把世界边界移出视口。影像和云掩膜统一投影并裁剪在该世界范围内。
- 点击地图或左侧列表中的影像时，顶部导航栏、左侧搜索区和底部详情栏保持固定；若目标影像在列表可视区域之外，只滚动左侧影像列表，不滚动整个页面。
- “云掩膜”和“云量数字”分别使用独立勾选开关，但共用一个“云计算方法”下拉框。选择综合法、RDC、Omni 或最终结果后，掩膜与数字同步采用该方法；任一显示开关开启时方法下拉框可用，两者都关闭时才禁用。
- 四种掩膜叠加图统一使用 rasterio 读取并二值化，兼容 RDC/Omni 常见的 GeoTIFF 压缩和 16 位掩膜。最终结果存在时会参与后台云量计算；人工采用一种结果后，最终结果掩膜及其云量会立即在当前页面可用。
- “文字设置”中可取消“方法名称”。勾选时显示如“综合 20.1%”，取消后仅显示“20.1%”；该选项与文字颜色、字号一起保存在当前浏览器中。
- 多景显示时，当前“云计算方法”的掩膜请求拥有最高优先级。切换方法会取消尚未开始的旧方法请求，保留快视图缓存并立即请求新方法；短暂读取失败会自动重试，并在页面给出一次明确提示。
- 选中一景后，底部 meta 定位信息下方会列出综合、RDC、Omni、最终结果四种掩膜的实际完整路径；没有路径时显示“未找到”。如果百分比存在但地图叠加失败，页面会再次调用诊断接口并显示服务端返回的真实异常类型和错误内容，以区分原始 TIF、透明 PNG 缓存及浏览器显示阶段的问题。
- Windows 网络盘中的超长 UNC 路径会在文件存在检查、大小和修改时间读取、快视图读取及掩膜读取阶段统一转换为扩展长路径形式，避免外层目录、内层目录和文件名重复完整影像 ID 后超过传统 260 字符限制。
- 只在包含 JPG、TIF 的内层景目录检查 `<完整影像ID>_meta.xml`，不再向上扫描产品目录或根据数据库旧路径全盘搜索。
- XML 存在且四角完整时显示“meta.xml 四角坐标”；XML 缺失或解析失败时才读取同级 SHP 的真实多边形顶点。选中景底部会显示实际检查路径和失败原因。
- `meta.xml` 同时兼容 `Upper/Lower`、`Top/Bottom`、`LeftTop/RightBottom` 和嵌套四角点节点。快视图、云掩膜、影像边界和云量着色共用左上、右上、右下、左下四个真实角点；选中景会显示四个黄色角点标记、元数据文件名和顶边倾角。
- 页面自带 Natural Earth 1:110m 陆地多边形作为离线矢量底图，可在工具栏关闭。底图文件随程序安装，运行时不联网。
- 默认不使用在线瓦片，只显示本地矢量底图和经纬网格，因此内网可直接运行。滚轮以鼠标位置为中心缩放；拖动统一使用 Canvas 物理像素，高分屏下不会产生首次拖动跳跃。
- 可独立开关快视图、影像边界和 ID 标签；云掩膜可切换综合法、RDC、Omni 或已经加入待入库的最终结果。
- “云量着色”按所选方法的整景云比例给影像范围着色，适合先在空间范围内快速找出异常景。
- “云量数字”默认在每景中心用红色、中等字号显示综合法云量，可切换为 RDC、Omni、最终结果或不显示。“文字设置”可以调整颜色和 10–36 px 字号，浏览器会记住设置。
- “云掩膜”下拉框选择综合法、RDC、Omni 或最终结果后，对应掩膜会使用与快视图完全相同的四角点变形叠加到地图。
- “云量着色”现在控制云掩膜像素的颜色，可固定选择红色、黄色、绿色，或选择“按云量分级”。分级默认小于 10% 为绿色、10%–80%（含边界）为黄色、大于 80% 为红色；“阈值设置”可修改两个百分比，设置保存在浏览器中。
- 左侧复选框用于限定地图显示范围：未勾选时显示所有景；勾选任意景后，只显示勾选景。
- 影像列表标题提供“全选”复选框，对当前搜索和筛选结果执行全选或取消全选；部分选中时显示半选状态。列表卡片不再根据地图当前视野降低透明度，选中、未选中以及视野外的景始终保持正常清晰并可点击。
- 右侧工具栏提供“云量统计”窗口，按当前左侧筛选后的影像列表分别统计综合、RDC、Omni、最终结果的低云量、中云量、高云量景数。分级与云量着色阈值联动，默认 `<10%`、`10%–80%`、`>80%`；尚未算完或缺少对应结果的景单列为“无结果”。点击“导出Excel”会按当前筛选顺序生成 `.xlsx`，包含影像 ID、卫星、日期、计划号、四种云量、综合-RDC差异、IoU 和计算状态。

## 性能策略

- 盘阵根目录后固定拼接 `GSHC2IMPS\PRODUCT\YYYY\MM\DD\卫星\外层影像目录\完整影像ID`。外层目录由完整 ID 删除景号字段（如 `_0001`）得到；只检查成像当天和次日，不再递归遍历盘阵。
- 组合检索先按日期进入当天和次日目录，再按计划号过滤外层目录。
- 四种方法严格按完整影像 ID 检查固定路径，不枚举无关文件：综合法为 `Debug\Cloud\combined\<ID>_Cloud.tif`，最终结果为景目录同级 `<ID>_cloud.TIF`；RDC、Omni沿用各自 `dst512`、`dst_omni512` 规则。同级 `cloud.TIF` 不再回退充当综合法。
- 列表先读取小型 meta.xml；云掩膜由最多 2 个后台线程计算，列表中的“计算中”会逐景变为实际云量。
- 云量结果按掩膜完整路径、文件大小和修改时间缓存；文件未变化时再次打开直接复用。
- 云量和透明掩膜缓存同时校验掩膜文件内容指纹，算法原位覆盖文件时，即使路径、大小和修改时间完全相同也能识别新结果。大文件指纹只读取头部、中部、尾部三个固定小样本，不再为数百景完整读取上千个 TIF；每次重新搜索仍会生成新的页面加载批次号，避免浏览器继续使用上一批次的透明 PNG。
- 四种方法的云量在一次降采样读取后分别计算；某一种掩膜损坏或临时不可读时不会中断同景其他方法。已完成方法照常显示比例，失败方法显示“失败”并保留具体错误，不会永久停在“计算中”。
- 只加载当前地图视野内、当前打开图层所需的图片。
- 所有数据库查询、盘阵搜索和影像读取都必须先由用户点击加载按钮触发；网页打开本身不处理业务数据。
- 浏览器同时最多请求 2 张图片，避免网络盘并发读取过多。
- 快视图缓存为不超过 768 像素的 JPEG，掩膜缓存为透明 PNG；同一文件未变化时直接复用缓存。
- 普通多景浏览优先读取 `<ID>_thumb.jpg` 并请求 256 像素版本；只有选中本景后才读取普通 JPG 的 768 像素版本。
- 数据库中保存的旧盘符路径失效时，只按上述固定公式重定位，不再使用递归扫描兜底。

## 挑图结果

选择“采用综合 / 采用 RDC / 采用 Omni / 采用最终结果”时，行为与桌面挑图模块一致：只向 `pending_import` 生成待入库副本。点击“跳过”只写状态和 txt 标记。两种操作都不会删除原 JPG、综合法、RDC 或 Omni 结果。

第一版暂不在浏览器中绘制或修改云掩膜；精细画笔编辑仍可使用原桌面标注模块。Web 端已经支持把现有云掩膜透明叠加到快视图上。
