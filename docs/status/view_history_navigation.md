# Viewer 底部历史导航 · 2026-11-05 · 已定

中央舞台底部提供独立的「上一视点」「下一视点」按钮，按视野历史前进和后退。按钮间距 40px，点击高度 36px，雾白半透明底色、灰绿描边与轻微毛玻璃；默认弱显示，鼠标进入底部 48px、悬停或键盘聚焦时通过 170ms 动效浮现。触屏使用较高默认可见度与 42px 点击高度。没有有效历史时对应按钮禁用。

`stores/viewHistory.ts` 保存最多 80 个内存快照，内容为影像 id/源版本、归一化视野中心和源像素倍率、双 Pane 身份及活动侧。连续缩放在停止 280ms 后合并；拖拽在松手后合并。Camera 动画中间状态、正在播放的交替帧和巡览过程不逐帧记录。新操作截断前进分支；已删除、源版本变化或预览被释放的记录跳过，不重新加载影像。切换对比模式时重建当前模式的历史上下文；窗口尺寸改变后按当前 Pane 尺寸恢复中心与倍率。

恢复复用 Viewer 的 `animateViewsTo`，时长由 `VIEW_HISTORY_MS=250` 控制，减少动态效果时立即落位。支持单图、双图分屏，以及相同已载入配对的暂停交替对比。绘制期间和处理影像时禁用历史恢复。

自动巡览运行或暂停时隐藏导航，巡览胶囊退场完成前也保持隐藏，避免 Camera 所有权和底部控件重叠。打开影像后的提示向上避让导航。感应区域不铺透明捕手，按钮以外的舞台缩放、拖拽与鹰眼事件沿用原机制；卸载取消历史定时器、动画和监听器。

验证：736 项单测、typecheck、build 通过；`.e2e/test-view-history.js` 覆盖手势合并、250ms 中间帧与终点、分支、缓存影像身份、键盘/触屏、减少动态效果、分屏、小窗口、巡览互斥和卸载；背景验收与双图交替验收通过。截图在 `.e2e/artifacts/view-history/`。生产大图与实体触屏设备仍待真机确认。
