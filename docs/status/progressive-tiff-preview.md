# TIFF 整图概览与后台渐进回填

2026-11-10。本记录对应第一阶段实现：本地 TIFF（包括已核对盘阵源后的本地读取）先给整图概览、再回填所选档位在现有内存预算内的预览，后台生成下载 JPG。不是服务端瓦片化已经完成的声明。

同日性能纠偏：用户反馈上一版更慢。确认独立概览预读、每批主线程确认对读取的反压、额外整幅中间画布及过严的 JPG 分流阈值会增加耗时。本地合成首屏变快不等于生产 X 盘端到端变快；下面记录的是纠偏后的行为。

## 已实现

- 选择与拖入 TIFF 核对服务端源后，仍优先走可接受的服务端 JPG。准入改为长边不超过 16384、总像素不超过 64 Mi，恢复常规约 3800 万像素预览的服务端路径；明显超限（如 24737×24727）的 JPG 仍保留源身份后分流本地。手动关联同样适用。阈值不是成功解码保证，不改用户档位，也不改服务端生成规则。
- 大图稀疏读取只采样一次。`sparseProgressive.ts` 把最终目标网格中分布全图的 32 行所在的既有读取组提前，以已读 DN 生成至多 256×32 的导航概览，再继续其余组；不另做 512 行概览采样，不重复读这些行。合并读取的区间、字节数和最终 DN 与原采样器一致，只改变读取顺序。
- Worker 发布 `preview`、`pixels`、`done`。概览和最终像素有确认门；中间行带按约 150ms 间隔限频，至多一批发送中，忙时跳过中间显示更新，不等待每批主线程确认才继续派发读取。进度消息也按约 80ms 限频，避免每次磁盘读都刷新 UI，起点/终点保留。跳过的只是显示帧，最终 DN 和最终画面不丢数据。每行不再必然经历两次拉伸与复制。
- 非稀疏/压缩路径撤销独立概览读取和为回填强制切换的带通处理，回到既有单轮解码策略；没有可复用概览时不强行先做一轮慢预览。Worker、合作暂停、停止和显示先于导出保留。这条路径不再声称一定渐进显示。
- 稀疏概览与中间细节共用优先行生成的固定显示统计，最终显示仍用这套统计，避免块间接缝与结束时整图跳亮。这些是近似显示统计，不是原图精确统计。最终 DN 沿用原采样算法；ROI 不读取局部完成的 DN。
- `progressivePreview` 为独立显示层。它不填充 `src`、不伪装最终完成状态、不参与差异检测或 ROI 数据输入；完整 DN 完成后才原子替换。已有完整影像换档时仍保留原数据，临时显示按原缩略图坐标换算覆盖，完整结果提交时保持视野。
- 概览到达后全屏遮罩变为右下角控制卡，支持查看概览、平移、缩放、暂停/继续和停止。中间显示层长边最多 2048，避免先分配并反复上传 8192² 整幅中间画布；最终画布只在完整像素完成时替换，保持原图视野。先发布完整像素，再生成长边不超过 4096 的下载 JPG；JPG 失败只提示导出失败，已显示影像保留。停止导出也保留完整像素；停止回填保留显示层，可点选重试。
- 根目录与 strip 数组不再依赖前 1/2 MiB。`tiffDirectory.ts` 按偏移读取有界 IFD 和外部值数组，兼容后置 IFD 与超过 4 GiB 偏移的 BigTIFF，并校验整数、文件范围和数组预算。

## 尚未覆盖

服务端独立打开场景（没有本地 File）的概览/瓦片接口、当前视野优先调度、多档细节瓦片缓存/LRU、自动后台标签页调度仍属于后续阶段。本次没有改变后端共享重任务队列。

本地最终预览仍遵守已有 `localPreviewSize` 的整幅 DN/Canvas 预算。档位保留，但预算不足时状态显示实际采样倍率；没有实现任意档位的原始细节按区域补齐。最终图仍使用整幅受限画布，并非无限大小的 tile 渲染器。真实 4.56 GiB / X 盘原图、所有生产压缩布局及内网耗时仍待核。

## 验证与复跑

新增测试覆盖整幅 JPG 准入、常规大图不强制读本地、行合并及全局拉伸一致性、读取不等待中间帧确认、单次采样读取集合及 DN 一致、显示先于导出、暂停时不发布及停止后的迟到结果、后置 IFD/BigTIFF 大偏移、超限源关联保留。

纠偏后前端全量 87 文件 / 995 项通过，随后增加进度限频测试并复跑单次采样/发布专项 8 项通过；术语检查、最终 typecheck、生产 build 均通过。这是分次结果。最终拉伸也已按 64 行分批检查暂停/停止，逐字节对照原拉伸通过。完整显示预算和资源上限并未因此消失。

真实 Chromium 使用 10001×10001、约 95.5 MiB 的无压缩 TIFF，走真实 File、Worker、稀疏读取与 Canvas；服务端 resolve 和失败 JPEG 由夹具模拟。纠偏后最终观察概览约 177 ms、12 次显示更新、最终像素约 1594 ms（含主动暂停）；上一版同夹具曾约 315/2163 ms、59 次更新。两次本机观察不代表生产盘阵提速比例。另生成真实 2049×2049、16bit、DEFLATE、64 行条带 TIFF，走 chunked 单轮路由：不做独立概览/回填，最终像素约 516 ms，抽查五处 DN 正确。验证暂停后像素不变、完整 DN 先于 JPG、停止导出保留像素、停止回填不发布最终 DN、重试不伪造盘阵身份。纠偏证据：`.e2e/artifacts/progressive-load-single-pass-report.json`；上一版历史数据保留在 `progressive-load-report.json`。
