# 自动巡览（2026-11-04）

工具栏下采样右侧无人机图标只打开设置，用户显式开始后才驱动现有 `setPaneView`。第一版仅允许单景、非对比、非编辑状态，不读取真实生产影像，不新建解码或预取链路。

## 文件与状态

- `lib/autoTour.ts`：原图像素空间蛇形网格规划、85% 视野步长上限、边界裁剪、匀速段及端点加减速。
- `stores/autoTour.ts`：idle / playing / paused，rAF 时间差驱动，控制现有 Camera；缩放不超过预览 1:1。路线最多 4096 点，超限说明原因，不能形成路线也说明原因。
- `AutoTourButton.vue` / `AutoTourControls.vue`：设置、范围、三档速度、循环、播放控制、页面隐藏与 reduced-motion 监听。退出 Viewer 后停止并清理临时状态。
- `MiniNavigator.vue`：仅绘制同一条实际路线与当前位置，保留视口映射和用户收起选择。
- Viewer 仅额外暴露已有 `stopViewAnim`，不重写渲染或坐标算法。

初始定位 1000ms；速度 70 / 110 / 160 屏幕 px/s；每段两端各约 300ms 加减速，短段相应缩短，节点停留 300ms；循环到端点后反向连续返程。控制胶囊沿用 200ms motion token；Hover 150ms。长帧最多消费 100ms，避免卡顿后瞬间大跳，因此严重掉帧时实际速度会降低。

手动 Camera 操作、用户意图事件、编辑会暂停。暂停按钮和后台隐藏不重置路段进度；手动接管后主动继续会先平滑返回暂停时的路线位置，再继续前进。切景、改变预览、窗口大小或切换对比后清空不再适用的路线，保留暂停说明，要求重新规划。没有自动恢复和停止时的强制归位。

## 验证

前端 686 项测试通过，typecheck、build 通过。既有 vendor sourcemap 缺失和大 bundle 警告仍存在。

`.e2e/test-auto-tour.js` 用合成 2400×1600 预览和 Mock API 验证入口不移动、启动运动、暂停视野稳定、继续、手动缩放接管、隐藏与恢复、Resize、掩码编辑、分屏切换、Esc、reduced-motion、页面卸载和页面异常。浏览器截图为 `.e2e/artifacts/submission-feedback/auto-tour.png`，已人工检查。

纯函数测试覆盖比例、真实像素边界、85% 步长、可见范围裁剪、小图拒绝、极端长宽比及匀速段。循环反向逻辑已实现，但完整长路线循环、实机大影像帧率与多尺寸完整视觉回归尚未专项验收。巡览仅辅助浏览，完成仅提示「巡览结束」，不代表检测或质量验收。
