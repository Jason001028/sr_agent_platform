# 自动修复区域与逐景展示

> 日期：2026-11-08 · 状态：本地实现；真实内网大图待核

## 修复区域

`/api/diff/analyze` 与智能修复共用差异检测、轮廓提取和源坐标映射。
`backend/services/repair_regions.py` 在源映射阶段整理最终修复区域：

- 相邻小区域合并，远距离区域保持独立。
- 每个修复区域使用四边形，满足 4～6 顶点要求；矩形包含原候选轮廓。
- 每个多边形以整幅影像面积的 2% 为软目标；不足时扩展，贴边时向图内平移。
- 分母为完整源影像；视野裁剪和原始 ROI 精算仍按完整源影像计算。
- 面积扩展与孔洞填充保留人工复核提示；不把主动扩展视为轮廓简化失败。
- 合并区域的所有连通域种子均参与源像素覆盖复核。

`autoMask.polygons` 包含 `merged_regions`、`full_image_area_ratio`、
`soft_min_area_ratio`、`soft_target_met`；`geometry_policy` 为
`repair-4to6-soft2pct-v1`。分析网格上的多边形可以超出 ROI，但源顶点限制在
实际影像内。覆盖范围只针对已检测的分析采样像素，不保证全分辨率缺陷召回率。

工具栏自动绘制先定位修复区域，再播放 SVG 描边，最后整批提交可编辑向量。
其撤销、重做、取消、源身份复核与手绘保留沿用既有事务。

## 逐景展示

Viewer 底部展示卡和任务设置中的“逐景定位与掩码动画”共用原自动跟随开关。
开启后按 Item ordinal 分页读取，依次执行：

```text
预加载下一景 → 打开当前景 → 等待真实检测结果
→ 定位每个修复区域 → SVG 描边与填充 → 停留 → 下一景
```

播放由 `frontend/src/stores/batchPlayback.ts` 编排，
`BatchRepairPlayback.vue` 负责展示，`scenes.preloadQuiet` 负责预加载。
预加载复用现有按源版本区分、按字节限制的预览缓存，不切换活动图；打开时重新 resolve，
以最新源版本读取或复用字节，缓存清空与按场景失效沿用共享缓存机制。后台检测、MaskBuilder 与 SR
调度独立运行；动画使用已生成的检测多边形，不伪造计算进度，不重复写掩码或提交任务。

- 分页游标仅在本景展示结束或跳过后推进，后台快速换景不会覆盖展示队列。
- 暂停、Esc、手动视图操作、绘制编辑和页面离开中断当前展示；继续时重播未完成景。
- 所有游标推进都检查当前播放归属；无差异停留期间的暂停和批次切换不会消费未完成景或污染新批次。
- 关闭掩码叠加停止跟随和播放，并清除播放轮廓；关闭通知独立于内部叠加显隐标记。
- 打开失败重试一次，区域结果加载失败重试三次，随后提示并继续。
- 网络中断保留游标并重试；切换批次取消旧请求，重新建立展示位置。
- 无差异景显示结果后继续；源版本不匹配的结果不叠加。
- 减少动态效果时跳过描边时长；每景仍展示结果。

后端原有生产准入与人工审核规则保持有效；展示暂停/跳过仅影响观看，不暂停或跳过后台作业。

## 验证入口

- 后端：`backend/tests/test_repair_regions.py`、`test_auto_mask_geometry.py`、`test_batch_difference.py`、`test_image_diff.py`。
- 前端：`frontend/src/stores/__tests__/batchPlayback.test.ts` 与既有差异/编辑回归。
- 浏览器：`.e2e/test-mask-auto-draw.js` 使用真实 Python 差异/几何和合成影像；`.e2e/test-repair-playback.js` 使用真实构建 UI、Viewer 相机与 SVG，以及只读合成批量接口。
- 浏览器截图与报告：`.e2e/artifacts/mask-auto-draw-*`、`repair-playback-*`。

本地验证：相关后端 61 项通过，前端全量 78 文件 / 936 项通过，类型检查与生产构建通过。
两条浏览器脚本均通过；单景合成样本输出 3 个四边形，分析与源映射覆盖均为 100%。
逐景合成样本验证中断后重播、下一景预加载、打开失败重试并继续；浏览器错误与禁止写操作均为 0。

真实盘阵影像的检测质量、扩大区域后的模型效果与 GPU 吞吐仍需内网验收。
