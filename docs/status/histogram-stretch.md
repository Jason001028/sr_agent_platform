# 交互式直方图拉伸

日期：2026-11-11。已实现并通过开发机合成影像验证，真实内网大图待验收。

## 用户入口

顶部原拉伸下拉替换为「直方图 · 当前模式」，没有增加第二个按钮。点击展开 340px 雾白浮层，提供「灰度调整」标题栏、分段统计范围、1024-bin 统计的聚合直方图、实际输入灰度刻度、黑白场拖柄与数值输入。参考用户提供的面板视觉，绿色用于选中控件，主体保持雾白。log 按钮只切换频数纵轴（log1p），不影响影像映射；曲线始终叠加在原采样直方图背景上。线性、2% 截断、均衡、平方根、对数五个模式直接平铺，下方额外提供曲线拉伸。普通模式手动修改上下限后标记「自定义」并使用线性区间映射；曲线模式调整上下限保留控制点。

拖柄支持 Pointer Capture，视觉细线外保留 22px 命中区域。键盘方向键调整、Shift 加大步长、Home/End 到端点，Escape 关闭并将焦点还给入口。窗口调整/滚动时重新定位，空间不足向上展开；无全屏遮罩。支持 prefers-reduced-motion。

## 数据语义

- TIFF 单波段使用缓存中的采样 DN。整图优先复用 BandStats，视野通过 Camera 和画布基准尺寸映射到缓存像素的可见矩形，再最多抽样 65536 像素统计。不重新读取或解码原 TIFF。
- 使用既有 1024-bin 直方图/CDF、stretchMap 和 stretchRgba；原有模式黄金结果保持，显式范围只扩展显示映射。
- 服务端 JPG 已经预拉伸，界面明确写「JPG 显示灰度 · 仅二次拉伸，不能恢复原始 DN」。本地显示件标记预览像素，不当作原始 TIFF DN。
- RGB 显示仍支持各模式；直方图展示首波段，自定义上下限应用到三个通道。双图共享当前限定为单波段，避免对不同通道含义做未经确认的共同映射。
- 原始 src、rec.stats、分析 token、ROI 几何、Mask、源文件和 SR 输入不变。显示结果写入 thumb/轻量显示画布；源统计与显示灰度统计不互相替换。已有 JPG 缓存和本地预览导出 Blob 不因调整显示而重写。

## 独立与共享

分屏和交替模式下显示「独立 / 共享」，默认独立，参数保存在各 ViewerRec。独立模式可明确选择 A/B 调整对象，交替模式选 B 时显示 B，不改变 Camera 或分析参考图身份；关闭浮层后入口仍对应当前活动图。共享使用同一上下限及同一个重分箱后的 CDF，并非只给两张图选择同名模式。

单波段 TIFF 必须确认同景，DN 位深、sampleFormat 和反相方式相同；缺少元信息或来源不兼容时禁用共享并说明原因。两张 JPG 可在 0–255 显示灰度域共用显示映射，但这不恢复原始 DN，也不证明两张图的辐射定标一致。TIFF DN 与 JPG 灰度不混合共享。更换比较对象或域变为不兼容时回到独立，已有各图显示参数保留。恢复默认会还原各图原来的起手模式，并回到独立映射。

## 实时显示与异步隔离

拖动事件通过 requestAnimationFrame 合并，轻量映射最多 512² 像素，复用轻量 Canvas。松手后使用当前缓存 src 分带重绘完整 thumb，每带约束到 128K 像素，主动让出主线程。完整绘制结束前，主画布和鹰眼使用同一轻量显示层覆盖，避免显露半新半旧的条带。

显示任务有独立代次，检查记录仍存在、src/Canvas/参数对象仍匹配，不递增分析 token，也不重置 Camera。新拖动会使旧绘制失效，关闭或换源后迟到结果不能复活卡片。源版本或数据域变更会清掉旧范围；同一源的档位变化保留显示参数。

稀疏渐进消息增加有界的 DN 块和统计，使用已有一次采样结果，不增加 TIFF 预读。主线程只保留最长边 1024 的临时 DN 概览，用同一参数版本映射已显示区域与后续块。临时 DN 不装入分析 src；最终 Worker 回传后重新应用当前参数，不能用启动时的默认 RGBA 覆盖用户设置。无原始像素的旧消息仍兼容原预览。

## 验证

纯函数和 Store 回归覆盖显式上下限、裁剪 CDF、共同数值域重分箱、视野统计、独立隔离、共享映射、混合域拒绝、恢复默认、异步覆盖及移除后的迟到结果。既有 TIFF/Worker/稀疏采样测试继续运行。

全量前端 93 个文件 / 1041 项测试通过；最终边界调整后的相关专项、typecheck 与生产 build 通过。既有 geotiff vendor 缺少 source map 的提示和 bundle 体积提示仍在，不影响这些验证。

实际浏览器使用生产构建夹具 `frontend/tests/histogram.html`，通过 agent-browser 的原生鼠标拖柄和键盘操作，检查 Camera、DN、stats、分析 token 不变；分屏和交替共享、视野统计及独立模式通过。

开发机 4096²（16777216 缓存像素）最后一轮拖动测试 12 次，轻量映射平均约 14.7ms、最大约 21ms；完整分带绘制完成。该数据仅证明合成缓存像素上的交互行为，不代表生产网络盘或 16384² 的耗时。真实 Worker 的 10001² 合成 TIFF 回填测试中，最终 2500² 缓存像素的 5 处抽查与自定义映射吻合，参数版本在概览、回填、最终图之间保持一致。

证据：`.e2e/artifacts/histogram-browser-report.json`、`histogram-progressive-report.json`、`histogram-unit-tests.log`；复跑脚本 `.e2e/histogram-acceptance.js`、`.e2e/histogram-progressive-acceptance.js`，夹具由 `.e2e/serve-local-load.mjs` 构建并提供。

界面截图：`.e2e/artifacts/histogram-single.png`、`.e2e/artifacts/histogram-shared.png`。独立选择 B、交替共享和键盘方向键/Escape 也经过浏览器验证。

部署只需更新完整前端 dist；Worker 与主线程消息结构应同版本发布。无需修改后端、重建 TIFF Overview 或重新安装 Windows 组件。
# 补充：曲线拉伸（2026-11-11）

五个预设（线性、2% 截断、均衡、平方根、对数）直接平铺，取消“更多模式”。曲线直接叠加在同一个直方图上，横轴与黑白场共用真实输入灰度坐标，纵轴为输出灰度。初始只有两个端点；点击图中任意位置新增点并可立即拖动，中间点可拖动输入及输出位置，端点可调输出，双击或 Delete/Backspace 删除中间点。图表获焦后 Enter 在最大空档插点，控制点方向键微调、Shift 加大步长，Home/End 调到黑/白。控制点采用分段线性插值，曲线坐标使用当前黑白场之间的归一化输入和 0–1 输出，可制作 S 曲线，也允许反向局部映射。重置曲线恢复对角线，恢复默认退出曲线模式。

曲线沿用 `stretchMap` 的显示链路、RAF 预览和分段完整更新，双图共享复制相同范围及控制点，调整黑白场保留曲线，选择其他预设清除曲线。原始 DN 不变。补充曲线像素映射、共享、范围调整、非法点拒绝与重置测试；相关 46 项测试、typecheck/build 通过，并完成浏览器鼠标拖动及键盘操作验证。
